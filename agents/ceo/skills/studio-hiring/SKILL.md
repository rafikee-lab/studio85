# Plan zatrudnień
| Kiedy | Rola | Model |
| --- | --- | --- |
| Start | CEO, Analyst, Red Team | CEO tańszy; Red Team inny model niż Analyst |
| Po G1 = go | Engineer | mocny |
| Gdy 1. produkt ma płacących klientów lub dane osobowe | QA, DevOps, Security Tester | wg dokumentu studia |
| Gdy jest co promować | Growth, Content & Social | wg dokumentu studia |
| Gdy 2+ produkty działają | CFO, Compliance, Support, Studio Ops | wg dokumentu studia |
Do tego czasu finanse, prawo i bezpieczeństwo = `studio-gate-checklists`; QA = akceptacja Board.

# Kroki
1. Sprawdź, czy moment z tabeli nastąpił. Jeśli nie — checklista albo czekamy.
2. Wniosek (`studio-escalation`): rola, dlaczego teraz, model, budżet miesięczny, przełożony, minimalne uprawnienia.
3. Po zgodzie Board utwórz agenta (`paperclip-create-agent`) z instrukcjami i skillami dostarczonymi przez Board.

# Zasady
Bez zgody Board nie zatrudniasz. Agenci czytający dużo treści z internetu — bez sekretów i bez akcji zapisu na zewnątrz.
